A simple Spring Boot + Spring AI MCP Server project that demonstrates how to expose existing customer functionality as MCP tools and connect them with AI clients such as Claude Desktop.

This project is created as part of the accompanying Medium tutorial.

What This Project Demonstrates

In this project, we will:

Start with a simple customer REST service
Add Spring AI MCP Server support
Expose customer functionality as an MCP Tool
Run the MCP server locally
Connect the MCP server to Claude Desktop
Use natural-language prompts to interact with the customer service

The goal is to demonstrate how an existing Spring Boot service can be extended with MCP without rewriting the underlying business logic.

Prerequisites

Make sure you have the following installed:

Java 21
Maven 3.9+
Git
Claude Desktop (for testing the MCP server)
